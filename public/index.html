Configurar botón en 1 clic desde esta web (opcional, solo 1 vez)

Guarda un Fine-grained Personal Access Token solo en este navegador (nunca se sube a GitHub) para disparar el escaneo directamente sin salir de ChapaAlToque PE:

  1. Abre Crear token en GitHub ↗.
  2. En Repository access, elige Only select repositories → DESCUENTOS-PROM.-TIENDAS-PERU.
  3. En Repository permissions → Actions, selecciona Read and write y genera el token.
